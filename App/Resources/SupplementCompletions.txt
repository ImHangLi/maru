# Smart completion for common supplements (D043). The add screen shows these values as candidates only.
# Nothing fills until the user taps. Only for supplements: a medication gets no candidate.
#
# One supplement on each line, with six fields after the name, separated by "|":
#   name | form | amounts | times | note | source
# - name: a name in SupplementNames.txt. Its aliases there match too.
# - form: capsule, tablet, softgel, powder, or drop. Empty when no one form is usual.
# - amounts: one to three amounts in the style of the amount field, separated by ";".
# - times: morning, noon, or evening, separated by ";". Only for a widely stated time of day.
# - note: "with food", "empty stomach", or a short text. Only for a widely stated direction.
# - source: where the convention comes from. "label" is a common direction on US labels.
#   "ODS" is a fact sheet of the NIH Office of Dietary Supplements. "FDA" is a required label text.
# An empty field means no candidate: when a convention is not clear, the field stays empty.
# Written from general knowledge of common labels. It is not medical advice, and it is not a copy of a database.
#
