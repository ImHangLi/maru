# Name and trademark check for "Maru"

Date: 2026-10-13. A desk study for the App Store release (D051). It follows `2026-10-12-store-name-and-languages.md`.

This note is not legal advice. It is a search of public data by a non-lawyer. Section 8 lists what a trademark attorney must still check.

## 1. Verdict

Keep "Maru" as the brand, and ship with a descriptive store name such as "Maru: Know What You Took". No search found a live "MARU" mark for health software, medication reminders, or health services in a searched register. No app in the eight searched storefronts has the exact name "Maru". The main weakness is not a conflict. "Maru" is a common word and a common name, so many owners use it, and the maintainer can protect it only narrowly.

| Market | Risk | Reason |
|---|---|---|
| United States | Low | No live "MARU" mark in class 9 or class 44. The nearest mark is MARU AI in class 42 for software development tools. |
| Australia | Low | The live exact marks cover clothing and toys. One pending mark, MARU Academy, covers education software. |
| European Union, Germany, Spain | Medium | The EU mark MARŪ covers "downloadable computer software applications" in class 9. The owner makes audio products. |
| United Kingdom | Medium | The UK copy of the same MARŪ mark exists. A figurative MARU mark covers dietary supplements in class 5. |
| Japan | Low to medium | No live plain "MARU", "まる", or "マル" mark was found in classes 5, 9, 10, 42, or 44. The word is very common, so a registration may be hard to get. |
| Korea | Medium | "마루" is a common word and many marks use it. Dr.maru covers supplements in class 5. A registration may be hard to get. |
| China mainland | Low to medium, not complete | The class 9 "MARU" marks found cover gauges and diving goods, not software. The search covered only a public mirror. The first release may not ship in this store (ICP filing). |

Readings:

- No searched register has a live plain "MARU" mark for medication reminders, health software, or health services in class 44.
- The EU and UK MARŪ mark is the only live mark that names software applications. Its owner sells audio products. It is more than five years old, so a third party can ask for proof of use. An attorney must judge the conflict.
- The UK class 5 mark covers supplements, and the app reminds about supplements. Software and supplements are different goods. A buyer can still connect the two, so an attorney must look at it.
- Dead US marks show that "MARU" for class 9 and class 42 was filed and abandoned more than once. No owner holds the plain word there now.
- The plain word marks in Japan are in classes 20, 24, 25, 33, 35, and 43. They do not touch software or health.
- The field is crowded. The maintainer can use the name, but a registration protects mainly against close copies in the same goods.

## 7. Recommendation

1. Keep "Maru" as the brand. Use "Maru: Know What You Took" as the store name.
2. Create the app record in App Store Connect soon. This is the only proof that the store name is free, and it reserves the name. It is a maintainer decision.
3. Remove "quiet" from the store name candidates, and consider it again for the subtitle.
4. Do not write the name as "MARŪ" with a macron. Do not use "ピルマル" in Japanese text.
5. Register the handles soon: `maru_day` on X and Reddit, and `maruday` or `maru-day` on GitHub and Product Hunt.
6. Before the EU and UK store pages are final, ask an attorney about the MARŪ class 9 mark and the UK class 5 mark.
7. A filing is optional for a free app. If the maintainer wants protection, the usual first step is an Australian application for the word "MARU" in class 9, then a Madrid application for other markets within six months.

Rough public fees, as information only. Check each office before a decision:

| Filing | Rough official fee |
|---|---|
| IP Australia, one class, standard goods list | About AUD 250 |
| IP Australia TM Headstart, an assessment before the filing | About AUD 200 and then AUD 130 for each class |
| USPTO, one class | About USD 350 |
| EUIPO, one class | EUR 850 |
| UK IPO, one class | About GBP 170 to 205 |
| JPO, one class | About JPY 12,000 to file and JPY 32,900 to register |
| Madrid System | CHF 653 basic fee, and a fee for each country |

Attorney fees are extra. A US filing from Australia needs a US-licensed attorney.

## 8. What an attorney must still check

- Unregistered rights and use in trade, for example passing off in Australia and the UK, and common law marks in the US.
- Similar marks by sound and look, for example MAROO, MARUU, MARO, and MALU. This study searched only the word "maru".
- Figurative marks and logos, and the app icon against circle logos.
- The exact goods of the Japanese marks and their similar-group codes in J-PlatPat.
- The Chinese register in full, and the Chinese subclasses for software (0901) and health services.
- Proof of use and the true scope of the MARŪ marks in the EU and the UK.
- Whether "Maru" is distinctive enough to register in Japan and Korea.
- Company names and domain disputes.

## 9. What was not searched, and why

- App Store Connect name availability: only the creation of an app record shows it, and this study must not create one.
- The App Store web search pages: the iTunes Search API gave the same data in a form that a script can filter.
- J-PlatPat, KIPRIS, IP Australia, the UK IPO site, EUIPO eSearch plus, and the WIPO Global Brand Database as separate sites: TMview holds their data, so one search covered them. TMview can be days or weeks behind an office.
- CNIPA: the official site needs a real session and often a CAPTCHA. Only the TMview copy was searched, and its Chinese data may be incomplete.
- Phonetic, figurative, and Vienna-code searches.
- Xiaohongshu handles, as section 5 says.
- Reddit, X, Instagram, and Product Hunt sign-up forms: no account was created.
- General web results for companies named Maru: the web search tool returned little, so section 4 rests mainly on the registers and the stores.
